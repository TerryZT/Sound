# PRD.md — Sound Mound Learning System

## 1. 产品背景
传统拼读与阅读工具只能判断“对/错”，无法判断学生对拼写规则的理解过程，导致教师重复、盲目教学。

## 2. 产品目标
- 捕捉学生对音素—拼写规则的真实认知判断
- 为教师提供可操作的教学诊断依据

## 3. 目标用户
- K–3 英语教师
- Reading Specialist
- 小规模班级教学场景

## 4. 核心使用场景
1. 学生完成系统引导的拼写映射任务
2. 系统记录决策路径
3. 教师查看规则混淆情况
4. 教师决定下一步教学内容

## 5. 功能范围（MVP）
### 学生端
- Today’s Task
- L1 Choice
- L2 Mapping（核心）

### 教师端
- 学生规则画像
- 班级规则分布

## 6. 非目标
- 游戏化
- 排名系统
- 自主学习路径

## 7. 成功标准
教师可以基于系统数据回答：
> “我下一节课该教什么规则？”
